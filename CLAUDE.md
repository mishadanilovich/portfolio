# Дом-портфолио — конвенции проекта

Сайт-портфолио: иллюстрированный дом в разрезе, подъём по этажам скроллом. Подвал — учёба, этажи 2–6 — проекты, гараж — пет-проекты, крыша — статус и контакты.

**Что читать перед работой:**

- `design/SPEC.md` — поведение, состояния объектов, анимации, требования к доступности. Источник истины по поведению.
- `design/tokens.json` — все цвета, шрифты, размеры, длительности.
- `design/mockups/` — эталонные экраны (`ru/01–12`, `en/01–12`, `00-design-system.html`). Это эталон **вида**, а не код для копирования.
- `portfolio-content.md` — весь контент RU/EN.
- `PLAN.md` — стадии разработки и текущий прогресс.

## Принятые решения и почему

Это осознанные отказы, а не упущения. Не «исправлять» без обсуждения.

| Решение | Почему |
|---|---|
| **Без GSAP / Framer Motion** | 90% анимаций здесь — «энум → transition», это умеет CSS. Библиотека весила бы за ноль пользы. План Б, если exit-анимации модалок станут неудобными |
| **Без i18next** | Два языка статического контента. Типизированные словари тree-shake'аются и проверяются компилятором |
| **Без Redux / Zustand** | Где ты в доме — это URL. Остального состояния на горсть useState |
| **Нативный скролл, без JS-камеры** | Перехват скролла ломает инерцию, адресную строку и жесты на телефоне. Это главное решение под будущую мобильную версию |
| **Квартира и гараж — роуты, не состояние** | Работает «назад», ссылки шарятся, страницы проектов индексируются. Сцена живёт в layout и не анмаунтится — отсюда непрерывность влёта в окно |
| **Tailwind для UI, CSS Modules для сцены** | Оба без рантайма. В сцене нужны keyframes и сложные селекторы, в хроме — быстрая раскладка |

## Правила сцены

Нарушение любого из них бьёт по производительности, особенно на телефонах:

1. Анимируем **только `transform` и `opacity`**. Никаких фильтров, блюров, анимации градиентных стопов.
2. Анимируем **обёртку-`div` транзформом, никогда SVG-атрибуты** (`x`, `y`, `d`, `width`) — это рерастеризация геометрии каждый кадр.
3. Слои — отдельные `<svg>` в позиционированных div'ах: небо / дальний план / дом / этажи / атмосфера.
4. Состояния объектов — **явный энум** (`idle | focused | entering`) через `data-state`, а не `:hover`. Тач-логика из SPEC (первое касание = фокус, второе = вход) пишет в тот же энум. `:hover` — только внутри `@media (hover: hover)`.
5. Циклические анимации — внутри `@media (prefers-reduced-motion: no-preference)` и на паузе за пределами экрана.
6. Геометрия дома — в абстрактных единицах с одним коэффициентом в px. Узкий вьюпорт меняет масштаб, а не раскладку.

## Доступность

В SPEC это первоклассное требование, не пожелание. Объекты сцены фокусируемые, с `aria-label`, Enter/Space работают как клик, фокус-кольцо 2px. Контраст не ниже AA — посчитанные пары лежат в `00-design-system.html`. В ESLint включён `jsx-a11y`.
