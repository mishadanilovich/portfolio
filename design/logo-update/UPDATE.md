## Что сделать
1. Компонент `Logo` (inline SVG, без `<img>`), пропсы: `variant: 'dark' | 'light' | 'mono'`, `size` (по умолчанию 36). Декоративный: `aria-hidden="true"`.
2. Шапка: знак 36 px слева от блока «Михаил Данилович / Senior Frontend Developer», `gap: 14px`, выравнивание по центру. Вся группа — одна ссылка «на главную», клик возвращает камеру к земле; `aria-label` у ссылки — имя.
3. Фавиконы: `favicon.svg` (`<link rel="icon" type="image/svg+xml">`) + PNG 32 и 16, `apple-touch-icon.png` 180×180 — сгенерировать из SVG при сборке или один раз скриптом.
4. Open Graph / превью ссылки: знак на `#2E3548` + «Дом-портфолио» (можно позже).
5. Анимация: при первой загрузке горящее окно (правое среднее) зажигается за 400 мс (`opacity 0 → 1`, ease-out). При `prefers-reduced-motion` — сразу горит.

## Правила знака
- Поле 64, корпус 40×50, скругление 2, линия 3.5, окна 9×9 сеткой 2×3.
- Горит только правое среднее окно, всегда `#F2B45C`; остальные окна — цвет линии.
- Минимальный размер основного знака — 24 px; меньше — только `favicon.svg`.
- Свободное поле вокруг — не меньше ширины одного окна. Не вращать, не обводить.
