# Обновление: ховер и состояния всех кнопок

Доработка поверх текущей вёрстки. Визуальный эталон — `mockups/buttons-states.html`: 14 типов × 5 состояний (обычное, наведение, нажатие, фокус с клавиатуры, недоступно).

Идея — «свет»: на наведении элемент чуть светлеет или теплеет, стрелки сдвигаются в сторону действия. Форма и размер не меняются.

## Общие правила
- Ховер только внутри `@media (hover: hover) and (pointer: fine)`. На тач — сразу состояние нажатия.
- Длительности: цвет, контур, тень — `150ms ease-out`; сдвиги (подъём, стрелки, поворот ×) — `200ms ease-out`; нажатие — `80ms`, без подъёма.
- Фокус: только `:focus-visible`, кольцо через `box-shadow: 0 0 0 2px <фон>, 0 0 0 4px <кольцо>`; кольцо `#F6C878` на тёмном, `#232938` на бумаге. На фокусе включается и ховер-вид.
- Недоступные (`disabled` / `aria-disabled="true"`): без ховера и сдвигов, `cursor: not-allowed`.
- `prefers-reduced-motion: reduce`: отключить `transform` (подъём, стрелки, поворот), цвет и контур оставить.
- Сделать токены `--motion-fast: 150ms`, `--motion-shift: 200ms`, `--motion-press: 80ms` рядом с текущими из `tokens.json`.

## Пример CSS (главная тёплая)
```css
.btn-primary {
  background: #F2B45C; color: #2A2116;
  transition: background-color var(--motion-fast) ease-out,
              box-shadow var(--motion-fast) ease-out,
              transform var(--motion-shift) ease-out;
}
@media (hover: hover) and (pointer: fine) {
  .btn-primary:hover { background: #F7C473; transform: translateY(-1px);
    box-shadow: 0 6px 18px rgba(242, 180, 92, .35); }
}
.btn-primary:active { background: #E3A447; transform: none; box-shadow: none;
  transition-duration: var(--motion-press); }
.btn-primary:focus-visible { outline: none;
  box-shadow: 0 0 0 2px #232938, 0 0 0 4px #F6C878; }
.btn-primary:disabled { background: #E9C894; color: #6B5A3E; cursor: not-allowed;
  transform: none; box-shadow: none; }
@media (prefers-reduced-motion: reduce) {
  .btn-primary, .btn-primary:hover { transform: none; }
}
```

## Проверка
- Пройти все 14 типов мышью, клавиатурой (Tab) и на тач-эмуляции.
- Контраст текста во всех состояниях ≥ 4.5:1, кольца фокуса ≥ 3:1 к фону.
- Включить reduced motion — сдвигов нет, цвет меняется.
