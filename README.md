# Дом-портфолио

Сайт-портфолио в виде иллюстрированного дома в разрезе. Дом — это карьера: подвал — начало пути, каждый этаж — проект, гараж — пет-проекты, крыша — текущий статус и контакты. Скролл вверх поднимает камеру от земли к крыше, то есть от первого места работы к сегодняшнему дню.

Михаил Данилович, Senior Frontend Developer.

## Стек

- **Next.js 16** (App Router) · React 19 · TypeScript
- **Tailwind CSS v4** для интерфейса, **CSS Modules** для сцены — оба без рантайма
- Сцена — плоские слои SVG, анимации только на `transform` и `opacity`
- Камера — нативный скролл, без перехвата. `IntersectionObserver` для состояний
- Два языка (RU/EN) из типизированных словарей, без i18n-библиотеки
- Форма для нанимателя отправляется в Telegram через Route Handler

Намеренно без библиотек анимаций, state-менеджера и i18n-рантайма — обоснования в [`CLAUDE.md`](CLAUDE.md).

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откроется на <http://localhost:3000>.

| Скрипт          | Что делает                   |
| --------------- | ---------------------------- |
| `npm run dev`   | Dev-сервер                   |
| `npm run build` | Production-сборка            |
| `npm start`     | Запуск собранного приложения |
| `npm run lint`  | ESLint                       |

Переменные окружения понадобятся только для формы-домофона — см. [`.env.example`](.env.example). Без них сайт работает, форма пишет в консоль.

## Материалы дизайна

Папка `design/` — исходная спецификация, по которой собирается сайт:

- **`SPEC.md`** — что строить: структура дома, поведение, состояния объектов, анимации, требования к доступности.
- **`tokens.json`** — цвета, шрифты, отступы, скругления, тени, длительности. Единственный источник значений: из него генерируются CSS-переменные.
- **`mockups/`** — эталонные экраны статичным HTML, открываются в браузере на ширине 1440:
  - `00-design-system.html` — палитра, типографика, компоненты, сводка анимаций;
  - `ru/01–12` и `en/01–12` — все экраны на двух языках.

`portfolio-content.md` в корне — весь текстовый контент с полями RU/EN, по нему строится контент-модель.
